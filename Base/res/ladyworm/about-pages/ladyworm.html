🐛 Ladyworm Neural Browser

Ladyworm is a proof-of-neural-operator browser fork based on Ladybird.

Extensions

🧠 Neural-Operator

Learnable function-to-function mappings for page prediction and prefetching.

Library: LibNeural

🌀 Wormhole State

Cross-tab neural state sharing. Tabs learn together and share predictions.

⚡ WebGPU Acceleration

GPU-accelerated rendering pipeline for neural computations.

🦎 Jank Integration

Clojure dialect targeting LLVM for browser scripting (coming soon).
